Why repeat finding?

DNA is not uniformly unique.

Genomic DNA is not uniformly unique. Repeated patterns can occur as tandem repeats, low-complexity sequence, or repeated sequence families distributed across the genome. A repeat finder should identify these patterns without depending on an alignment against a reference repeat library.

The problem

Find repetitive bases and patterns directly from DNA sequence using alignment-free sequence statistics.

The reference signal

Lowercase bases in the dataset's soft-mask provide a base-level reference for evaluating whether our detectors rediscover masked regions.

The challenge

Simple detectors can be sensitive but over-call ordinary sequence. The goal is to understand that precision–recall trade-off before adding machine learning.

Architecture

K-mer analysis

Counts corpus-wide canonical k-mers and identifies high-copy sequence. Repeated k-mers can flag interspersed repeats shared across windows.

Tandem repeats

Searches for adjacent repeated units with mismatch tolerance across periods 1–50.

Low complexity

DUST-style masking identifies sequence whose composition is unusually repetitive or low complexity.

What the metrics mean

Three questions about every detector.

Precision

Of the bases we called repetitive, how many overlap the soft-mask?

Recall

Of the soft-masked bases, how many did our detector recover?

F1

A balance between precision and recall. Useful when neither false positives nor false negatives can be ignored.

The headline result: the current system can recover most soft-masked bases, but it does so by calling too much sequence repetitive. Improving this trade-off is the immediate research problem.

The project in one minute

We are building an alignment-free human DNA repeat finder. Instead of starting from a repeat library, we analyze short genomic windows and use sequence statistics to discover repeated structure.

Our first milestone implements k-mer analysis, tandem-repeat detection and low-complexity detection, then compares their base-level predictions with the dataset's existing soft-mask.

On the complete dataset, the current union reaches 94.6% recall but only 11.6% precision. That means the baseline is highly sensitive but too aggressive — giving us a clear target for the next stage.

The next step is to improve that trade-off and then test a base-level CNN/BiGRU that can learn repeat patterns directly from sequence.
